# Flask MySQL Dictionary

A web-based dictionary application built with Flask, MySQL, HTML, CSS, and Bootstrap.

## Project Overview

This application allows users to search for words and retrieve their definitions from a MySQL database through a Flask web interface.

## Features

* Search for words
* Display word definitions
* Flask-powered backend
* MySQL database integration
* Responsive Bootstrap interface

## Technologies Used

* Python
* Flask
* MySQL
* HTML5
* CSS3
* Bootstrap

## Installation

1. Clone the repository:

```bash
git clone https://github.com/obeng-enoch/flask_mysql_dictionary.git
```

2. Navigate to the project directory:

```bash
cd flask_mysql_dictionary
```

3. Create a virtual environment:

```bash
python3 -m venv venv
```

4. Activate the virtual environment:

```bash
source venv/bin/activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
python app.py
```
